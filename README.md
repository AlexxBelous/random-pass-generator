# 🔑 Random Password Generator

Учебный пет-проект: генератор случайных паролей с гибкими настройками.

## 🛠️ Стек технологий

- **HTML5** — семантическая разметка
- **Sass/SCSS** — стилизация приложения
- **Vanilla JS (ES6+)** — логика генерации паролей и работы с DOM
- **Vite** — сборщик проекта и dev-сервер

---

## 📌 Функционал приложения

- [ ] Генерация безопасных паролей случайным образом
- [ ] Настройка длины пароля
- [ ] Переключатели параметров (заглавные/строчные буквы, цифры, спецсимволы)
- [ ] Быстрое копирование сгенерированного пароля в буфер обмена
